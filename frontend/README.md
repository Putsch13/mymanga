# Frontend (Web)

Le **frontend** de MYMANGA est l’application Next.js située ici :

- `apps/web`

Elle contient :
- Les pages UI (App Router)
- Les composants
- Les API routes (Route Handlers) qui servent d’API “backend” pour le navigateur

## Commandes

Depuis la racine :

- `pnpm frontend:dev`
- `pnpm frontend:build`
- `pnpm frontend:start`
